# desktop-service-app

A Cytoscape Desktop app that brings [service apps](https://github.com/cytoscape/cytoscape-web/wiki/Specification-for-Service-App-in-Cytoscape-Web-(draft-v2)) to Cytoscape Desktop. It installs them from the unified App Store, gives them menus and dialogs in Desktop, runs them, and exposes `serviceapps` automation commands.

Requires Cytoscape 3.10 or later.

Work is tracked in [cytoscape/cytoscape#28](https://github.com/cytoscape/cytoscape/issues/28).
